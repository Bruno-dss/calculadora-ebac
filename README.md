# calculadora-ebac

## Como executar o arquivo .sh

No terminal, acesse a pasta do projeto e execute:

cd ~/modulo1/python
chmod +x calculadora.sh
./calculadora.sh

O comando chmod +x concede permissão de execução, e ./calculadora.sh inicia o programa.

## Explicação do código Python
```
print("Sejam bem-vindos!")
print("Calculadora")
print(f'2 + 2 = {2+2}')
```
print() exibe mensagens na tela.

"Sejam bem-vindos!" apresenta uma mensagem de boas-vindas.

"Calculadora" exibe o nome do programa.

f'2 + 2 = {2+2}' utiliza uma f-string para calcular a soma de 2 + 2 e exibir o resultado.

Saída esperada:

Sejam bem-vindos!
Calculadora
2 + 2 = 4
